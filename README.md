# Кадр — Movie Studio

Самостоятельная режиссёрская студия для создания короткого анимационного фильма: от чернового сценария и образов героев до раскадровки, озвучки, видеопланов, синхронизации губ и итогового MP4.

Приложение сохраняет варианты, выбор и утверждения режиссёра на каждом этапе. Можно сравнивать модели и голоса, запускать серии генераций и учитывать предварительные, подтверждённые и неизвестные расходы.

**Развёртывание на своём сервере:** Node.js 24 + Next.js 16, SQLite и приватные файлы на диске. Docker Compose и HTTPS через Caddy включены. Аккаунт Sites и вход через ChatGPT для работы приложения не требуются. Для генерации нужны собственные API-ключи провайдеров.

## Быстрый запуск на VPS

Установите Docker Engine и Docker Compose, направьте домен на сервер и откройте порты 80/443. Затем:

```bash
git clone https://github.com/rdv77/movie_studio.git
cd movie_studio
docker run --rm --user "$(id -u):$(id -g)" -v "$PWD:/app" -w /app node:24-bookworm-slim \
  node scripts/setup.mjs --origin=https://studio.example.com --username=director
docker compose -f compose.yaml -f compose.https.yaml up -d --build
```

Замените `studio.example.com` своим доменом. Команда настройки создаёт `.env` и показывает случайный пароль входа один раз. Сохраните пароль. После запуска откройте домен, войдите и добавьте API-ключи в **«Подключениях»**.

Уже существующую `.env` настройка не перезаписывает. Данные переживают пересборку контейнера благодаря отдельному тому. **Не удаляйте тома при обновлении.**

## Что умеет студия

| Этап | Результат |
| --- | --- |
| Исходный сценарий | Отдельный черновик и задача для ИИ, альтернативные редакции |
| Герои | Имена, характеры, внешность, изображения-референсы и утверждённые образы |
| Визуальный стиль | Жанр, атмосфера и единая визуальная основа |
| Подробный сценарий | Планы с действием, длительностью, камерой, монтажными связями и репликами |
| Раскадровка | Изображения отдельно для каждого плана, массовая генерация |
| Голоса | Реплики из сценария, сравнение голосов на одной фразе, озвучка по планам |
| Аниматик | Просмотр раскадровки с выбранной речью и подгонкой длительностей |
| Видеопланы | Генерация из первых кадров, серии одной моделью, альтернативные дубли |
| Синхронизация губ | sync.so для выбранных кадров/видео и реплик персонажей |
| Финальная сборка | MP4 1080p/24 fps, выбранная озвучка, согласованные склейки |

Закадровая речь и речь героя различаются: промпты учитывают, должен ли персонаж двигать ртом. Удаление вариантов происходит без дополнительного подтверждения; удалённые варианты доступны для восстановления.

## Подключённые API

| Назначение | Адаптеры в этой версии |
| --- | --- |
| Сценарии | OpenAI GPT-6 Astra, Grok 4.6, MiniMax M2.7 |
| Изображения | GPT Image 2.5 Sunburst/Flare, Grok Imagine Image 2.0, FLUX.2 Pro, MiniMax image-01 |
| Видео | Grok Imagine Video 1.5, MiniMax Hailuo 2.3 |
| Голоса | MiniMax Speech 2.8 HD, ElevenLabs v3 |
| Синхронизация | sync-3, lipsync-2, lipsync-2-pro |

Это перечень реализованных адаптеров, а не гарантия доступа к моделям у любого аккаунта. Доступность, тарифы и поддерживаемые параметры определяет провайдер. GPT Image 2.5 создаёт изображения; видеогенерация выполняется отдельными моделями. Каталог находится в `lib/models.ts`, адаптеры — в `lib/providers.ts` и `lib/sync-provider.ts`.

## Локальная разработка

Требуется Node.js 24.15+ (ветка 24 LTS).

```bash
npm ci
npm run setup
npm run dev
```

Откройте `http://127.0.0.1:3000`. Для производственного Node-запуска: `npm run build`, затем `npm start`. Оба режима выполняют миграции перед запуском; `npm run db:migrate` запускает их отдельно. `npm run prepare:media` готовит локальные файлы FFmpeg, а перед production-сборкой вызывается автоматически.

## Проверка

```bash
npm run prepare:media
npm test
npm run typecheck
npm run build
npm run test:integration
```

Тесты используют временные базы и фиктивные ответы провайдеров. Они проверяют авторизацию, сохранение после перезапуска, шифрование ключей, Range-запросы, загрузки 57 МиБ частями, большие снимки проекта, утверждения, работу с голосами и реальные тестовые MP4. Платные генерации не запускаются. GitHub Actions выполняет проверки и собирает Docker-образ.

## Границы этой версии

- Один владелец, один Node-процесс и локальный постоянный диск. Многопользовательская регистрация и горизонтальное масштабирование не реализованы.
- Целевой фильм — 45–60 секунд. В обычной массовой видеогенерации адаптеры настроены на клипы по 6 секунд; длинные планы требуют разделения.
- Очередь обслуживается открытой вкладкой выбранного проекта. После закрытия страницы она продолжится при следующем открытии; уже принятый провайдером запрос может выполняться независимо.
- Монтаж FFmpeg и подготовка файлов для sync выполняются в браузере. Закрытие вкладки прерывает локальную сборку; большой сервер не ускоряет её.
- Пользовательские загрузки до 1 ГиБ передаются частями; прямой endpoint и сохранение файлов от провайдеров ограничены 50 МиБ. Возможность загрузить файл не гарантирует, что памяти браузера хватит на монтаж.
- API-ключи шифруются с помощью `VAULT_KEY`; резервная копия должна включать настройки и **весь** каталог данных. Старые версии объектов пока не удаляются автоматически, поэтому следите за диском.
- Репозиторий не содержит фильмы, голоса, фотографии, базу или API-ключи рабочей студии. Их перенос — отдельная операция, описанная в документации.

## Компоненты третьих сторон

Интерфейс использует React, Next.js, Tailwind и компоненты shadcn. FFmpeg WASM загружается из зафиксированных npm-пакетов при подготовке сборки; лицензии и ссылки на исходники указаны в [уведомлении](public/ffmpeg/NOTICE.txt). Не удаляйте уведомления при распространении собранного приложения.
