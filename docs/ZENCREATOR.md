# ZenCreator

## Подключение

1. Создайте API-ключ в [кабинете ZenCreator](https://app.zencreator.pro/api-keys) с правами **read** и **generate**.
2. В студии откройте **Подключения → ZenCreator · агрегатор**, вставьте ключ и нажмите **Сохранить**. Он хранится в существующем зашифрованном хранилище сервера, не в исходном коде.
3. Нажмите **Проверить ключ и баланс**. Проверка читает каталог и количество кредитов, не запускает генерацию. Право `generate` и фактическая возможность выполнить запрос проверяются при запуске.
4. На нужном этапе откройте **Создать с ИИ**, в поле **Найти модель** введите `ZenCreator` либо название модели. Можно сравнить все подключённые модели одного типа, включая прямых провайдеров, и получить несколько вариантов от каждой.

## Модели по задачам

| Задача | Подключённые модели |
| --- | --- |
| Сценарии, характеры, текстовые правки | Grok, Hermes 3 405B, Euryale 70B |
| Герои, образы, локации, раскадровка | Nano Banana, Qwen Image / Pro, Seedream 5 / Pro, Wan 2.7 Image / Pro, FLUX Klein |
| Видеопланы | Grok 4.1 Video, Kling 2.6, MiniMax 3.0 / Turbo, Seedance 1.5 Pro, Seedance 2.0 / Fast / Mini, Wan 2.6 Flash, Wan 2.7, Wan 3.0 |

Модели доступны и при массовом создании раскадровки и оставшихся видеопланов. Новые варианты требуют обычного просмотра и утверждения режиссёром. Ранее созданные материалы сохраняются.

Каталог студии содержит совместимые с её текущими задачами профили; это не все инструменты агрегатора. Доступ конкретного аккаунта проверяется по актуальному `/tools` перед платным запросом. FLUX Klein требует доступа Trusted. Каталог проверки показывает отдельный доступ к изображениям с референсами.

## Параметры и ограничения

- Текст: промпт с утверждённой основой до 32 000 символов, ответ до 4096 токенов. Текстовые модели ZenCreator в студии используются без изображений.
- Изображения: один результат на попытку. Полный промпт — до 5000 символов, включая задачу, описание героя или текущего плана и утверждённый стиль. Длинные части сокращаются в отдельном промпте, который виден перед запуском; исходные карточки сохраняются полностью. Сценарий целиком и служебная история в такой запрос не входят. Без референсов используется `by_prompt`, с ними — `image_editor`. Референсы передаются напрямую файлами в исходном порядке, без публичных ссылок на библиотеку. До восьми PNG/JPEG/WebP, до 10 МБ каждый и 20 МБ суммарно; более строгие ограничения актуальной схемы API проверяются до генерации. Формат соответствует фильму; для моделей с переключателем `tier` выбрано 2K. Дополнительное переписывание промпта выключено.
- Видео: первый кадр и промпт конкретного плана с указаниями по героям, камере и закадровой/экранной речи; 720p. Kling 2.6 и Wan 2.7 запрашиваются на 10 секунд, остальные профили — на 6 секунд. В монтаж входят первые секунды по длительности плана (до 6 секунд). Полный исходный ролик доступен в варианте. Продолжительность показывается до запуска.
- Генерация собственного звука отключена, где API позволяет. Grok и MiniMax могут всегда возвращать встроенный звук. Это не замена утверждённой озвучке и синхронизации губ в студии.
- Wan 3.0 может ждать 15–55 минут. Пока открыта студия с проектом, она проверяет очередь каждые пять секунд; после возвращения продолжает проверку сохранённого запроса.
- Отдельный синтез речи ZenCreator в этой интеграции не подключён; используйте существующие голосовые модели. Синхронизация губ остаётся отдельным этапом.

## Расходы

Оценка ZenCreator показывается **в кредитах** за попытку и серию, сохраняется в журнале и выгружается отдельной колонкой CSV. Цены взяты из публичного каталога 16 сентября 2026 года и могут измениться.

API результата не возвращает подтверждённое списание за конкретный запрос. Поэтому оценка не записывается как факт, кредиты не превращаются автоматически в доллары, а изменение общего баланса не приписывается отдельной попытке. Фактический расход проверяйте в кабинете агрегатора. При долларовом лимите проекта заполните собственную оценку USD; неизвестные списания сверяйте обычной кнопкой **Сверить**.

## Для разработчика

- REST: `https://api.zencreator.pro/api/public/v1`, Bearer-ключ.
- Каталог совместимых профилей: `lib/zencreator-models.ts`; обработчик: `lib/zencreator-provider.ts`; чтение подключения: `GET /api/connections/zencreator` (проверка владельца, `private, no-store`). Ключ никогда не возвращается клиенту.
- Загрузка `POST /assets` с multipart `file` + `media_type`, затем один `POST /generations` с `Idempotency-Key`, равным UUID сохранённой попытки. При потере связи платный запрос не повторяется автоматически.
- `GET /generations/{id}` и `/result` читают сохранённую задачу. Сохраняется оригинал `download_url`, не уменьшенное превью `url`. При повторном сохранении файла ссылка запрашивается заново, генерация не повторяется.
- Никаких новых переменных окружения или миграций таблиц не требуется: используется хранилище подключений и существующая версия JSON проекта. Данные `zenCreditsEstimate` необязательны для старых проектов.
- Проверки: `node tests/zencreator.mjs`; на Sites дополнительно `node tests/zencreator-worker.mjs`. Ответы провайдера замоканы; платных запросов нет.

Контракт и цены: [официальная документация](https://api.zencreator.pro/api/public/docs), [OpenAPI](https://api.zencreator.pro/api/public/openapi.json).
