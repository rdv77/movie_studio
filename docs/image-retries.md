# Повторы генерации изображений и резервная модель

В окнах создания героя, локаций, кадров раскадровки и массовой генерации есть блок «Повторы и резервная модель».

1. Выберите основные модели и количество вариантов. Это число различных результатов, а не число повторов.
2. Укажите 1–3 попытки основной моделью, включая первый запуск. По умолчанию — 3.
3. При необходимости выберите одну резервную модель из подключённых провайдеров. После исчерпания попыток основной модели она получит один запрос. При совпадении с основной дополнительного запуска не будет.
4. Запустите новую серию. После первого успешного изображения цепочка прекращается. Выбор и утверждение результата остаются за пользователем.

Повторяется подтверждённая ошибка генерации без результата или отклонённый HTTP 429 при первоначальной отправке. Между попытками — 15 секунд; очередь сохраняет общие и провайдерские ограничения параллелизма. HTTP 429 при проверке уже принятой задачи повторяет проверку её номера, а не генерацию.

Ошибки ключа/баланса, валидации, отказы по содержимому, некорректные адреса файлов и неизвестный исход не вызывают автоматическую повторную оплату. Если файл уже сохранён, используйте «Восстановить сохранённую картинку» в журнале. Ошибка сохранения результата продолжает сохранение, а не генерацию. Остановка ожидания не перезапускает цепочку.

Каждая попытка имеет свой ID, строку журнала, квитанцию и стоимость. В журнале видны номер попытки, идентификатор цепочки и причина остановки. Оценка при использовании всех попыток не является подтверждённым списанием. Перед каждым новым запросом проверяется лимит проекта; неизвестные списания при установленном лимите требуют сверки.

Промпт резервной модели компилируется и проверяется при создании серии под её собственные ограничения. Сохраняются исходные сцена, герои, референсы и источник первого кадра. Изменение основы или исключение референса останавливает следующий запрос. Для конечного/промежуточного кадра разрешено переключение на явно выбранную резервную модель с сохранением того же первого кадра. Старые серии без настройки повторов автоматически не запускаются.

Проверка: node tests/image-retries.mjs. Все ответы API имитируются, платных генераций нет.
