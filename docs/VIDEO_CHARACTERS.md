# Выбор героев для генерации видео

В «Видеопланах» откройте «Создать с ИИ» → «Серия вариантов». В блоке **«Утверждённые герои»** снимите галочки с тех, чьи образы не нужны в этой серии. Кнопки «Выбрать всех» и «Снять все галочки» меняют выбор сразу для всех героев.

Студия добавляет в видеопромпт описания только отмеченных героев. Grok также получает только их отдельные изображения. Другие видеомодели получают выбранный первый кадр и описание. Можно снять все галочки: в таком случае автоматический блок с описаниями героев и отдельные изображения персонажей не отправляются.

Посмотрите «Полный промпт для модели» перед запуском. Имена и указания, уже написанные в задаче вручную или взятые из сценария, не удаляются при снятии галочки. Первый кадр тоже остаётся прежним: если на нём нарисован лишний персонаж, выберите или подготовьте другой кадр.

Исключение из серии не удаляет героя из проекта, не снимает его утверждение и не меняет предыдущие ролики. Выбор записывается в результат генерации и восстанавливается при открытии новой серии для выбранного результата. Если закрыть окно без запуска, черновой выбор не сохраняется.

В окне «Создать оставшиеся видеопланы» есть такой же блок. Выбор в нём действует на все отмеченные планы этой серии. Если состав героев отличается, запускайте отдельные серии.

Для старых запросов без явного выбора сохраняется прежнее поведение: все утверждённые герои. Сервер проверяет принадлежность выбранных героев проекту и актуальность утверждённых образов перед сохранением очереди.
