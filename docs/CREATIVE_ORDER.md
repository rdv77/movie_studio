# Стиль и локации до героев

Начало работы: **Общий сценарий → Визуальный стиль → Образы и локации → Герои → Подробный сценарий**. Затем следуют раскадровка, голоса, аниматик и остальные производственные этапы.

Идентификаторы этапов в сохранённых проектах не меняются. Порядок отображения и проверки зависимостей отделён от этих идентификаторов. Перестановка не переписывает варианты, фотографии, расходы и утверждения. Утверждённые герои, стиль и локации сохраняют утверждение после правок предыдущих этапов; новые генерации используют текущую основу. Уже поставленный запрос со старой основой не отправляется провайдеру.

Для создания героя сначала утвердите стиль и локации. В промпт каждой модели изображений автоматически входят краткие описания этих утверждённых материалов — в том числе описания локаций, созданных как изображения, даже если их файлы не отмечены референсами. Текстовый контекст не добавляет фотографии к запросу: отправляются только выбранные изображения.

Карточка героя, внешность, указания по фото и задача режиссёра объединяются с коротким контекстом мира. Стиль и локации получают отдельные доли бюджета промпта. Для MiniMax image-01 весь промпт ограничен 1500 символами, для остальных моделей изображений — консервативным бюджетом студии 4000 символов. Полный сценарий, история вариантов, служебные идентификаторы и описания других героев не включаются.

Сокращение локальное, без дополнительного платного запроса к LLM: пробелы нормализуются, длинные части ограничиваются по выделенному бюджету. Исходные описания остаются целиком. В «Серии вариантов» раскрывается точный промпт каждой модели и его длина; перед запуском проверьте, что существенные детали остались.

Локации задают мир и освещение персонажа; портрет сохраняет простой фон для удобства дальнейшего использования. Ранее созданные изображения автоматически не перерисовываются — новый стиль будет использован при следующей генерации.

Проверки: `node tests/creative-order.mjs`, `node tests/character-image-prompt.mjs`, `node tests/creative-approval.mjs`.
