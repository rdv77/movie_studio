# Сравнение вариантов

На общем сценарии, героях и подробном сценарии доступна вкладка «Сравнить тексты». Выберите версии независимо слева и справа. Отличающиеся абзацы подсвечены, происхождение, параметры и расход раскрываются у версии. Просмотр не меняет выбор и не запускает генерацию.

«Выбрать эту версию» сохраняет выбор; утверждение выполняется отдельно. Включите объединение, отметьте нужные абзацы и отредактируйте результат: сохранится новый вариант с двумя источниками. Старые варианты сохраняются.

В структуре сцен и проработке планов откройте «Сравнить версии сцен в двух окнах». Выбор версии структуры создаёт новую ветвь всей структуры, выбор в подробной проработке переносит только текущую сцену. Готовые файлы и расходы не откатываются. После изменения проверьте совместимость зависимых материалов.

История исходного описания героя также сравнивается рядом. Возврат описания не заменяет утверждённую картинку героя.
