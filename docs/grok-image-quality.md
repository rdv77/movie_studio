# Качество изображений Grok

В «Серии вариантов» и «Создать кадры всех планов» при выборе Grok Imagine Image 2.0 доступен режим качества. Новая генерация по умолчанию использует финальный `medium / 2k`. Для чернового сравнения выберите `low / 1k`. Автоматической замены режима после ошибки нет.

Режим сохраняется в задании и результате, показывается на карточке и в журнале. Старые задания без параметров продолжают использовать прежний `low / 1k`. Редактирование описания существующего изображения сохраняет его происхождение.

Смета рассчитывается сервером: финальный результат $0.08, черновой $0.04, плюс $0.01 за каждое отправленное изображение. В массовой раскадровке каждый план имеет собственные референсы и собственную смету; общий расход — их сумма. Поле оценки Grok доступно только для чтения. Фактическая стоимость учитывается отдельно по квитанции API; без квитанции она остаётся неизвестной.

Тариф проверен 1 октября 2026 по [странице модели](https://docs.x.ai/developers/models/grok-imagine-image-2.0) и [прайсу xAI](https://docs.x.ai/developers/pricing). Параметр `high` не поддерживается этим адаптером. Качество изображения зависит также от исходного кадра и постановки; увеличенное разрешение само по себе не исправляет композицию.
