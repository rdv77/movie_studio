# Работа камеры

Политика камеры задаёт общий подход оператора к фильму. Она не заменяет конкретную постановку плана и не заставляет камеру двигаться в каждом кадре.

## Выбор политики

Настройка **«Работа камеры»** находится в форме нового проекта и в творческом задании на этапе **«Общий сценарий»**.

| Политика | Как работает оператор |
| --- | --- |
| Преимущественно статичная | Предпочитает устойчивую композицию. Простое движение допустимо, если оно необходимо для показа действия или раскрытия информации. |
| Сдержанная кинематографическая | Чередует неподвижные планы с мотивированными наездами, отъездами, панорамами и сопровождением. Движение помогает показать эмоцию, действие или важную деталь. Это начальный выбор для нового проекта. |
| Динамичная | Чаще использует заметное движение, но сохраняет читаемость действия, ориентацию в пространстве и удобную склейку. Динамика не означает обязательный облёт или непрерывную тряску. |

В существующем проекте без этой настройки сохраняются прежние задания. Открытие проекта само по себе не назначает новую политику и не пересоздаёт материалы. Чтобы изменить подход, явно выберите режим и нажмите **«Сохранить творческое задание»**.

## Что получает специалист-оператор

Оператор учитывает политику камеры вместе с жанром, стилем, действиями персонажей, актёрскими задачами, длительностью и соседними планами. Для каждого плана он описывает:

- начальную и конечную крупность;
- тип и конкретную траекторию движения либо статичную композицию;
- зачем нужна выбранная работа камеры;
- темп движения, момент его начала и остановки;
- героя или предмет, который должен оставаться в кадре;
- конечную композицию и переход к следующему плану.

Эти поля доступны в **«Подробном сценарии» → «Правки четырёх частей» → «Движение камеры»**. Начальная и конечная крупность находятся выше в той же форме. У одного плана может быть статичная камера, даже если политика фильма динамичная: конкретное утверждённое задание имеет приоритет при генерации.

Режим **«Простые и ясно читаемые действия»** совместим с движением камеры. Например, герой переводит взгляд, а камера медленно приближается. Для сложного действия руками оператор может оставить камеру неподвижной, чтобы не затруднять генерацию и восприятие.

## Как применить политику к уже подготовленному фильму

1. Выберите политику в творческом задании и сохраните его.
2. Откройте **«Подробный сценарий»**. В каждой нужной сцене запустите доработку **«Оператор»** для выбранных планов. Сохранение настройки само по себе не переписывает утверждённые операторские задания.
3. Проверьте крупность, движение и его задачу. При необходимости поправьте поля вручную. Сопоставьте начальную композицию с уже выбранным изображением раскадровки.
4. Запустите проверку фильма редактором, решите замечания и утвердите готовые планы.
5. Нажмите **«Подготовить промпты и применить сценарий»**. Дождитесь завершения: генерация видео использует опубликованную основу подробного сценария.
6. Пересмотрите отмеченные изменившимися изображения. Подходящие картинки можно оставить и подтвердить; новые нужны только там, где прежняя композиция уже не соответствует постановке. При необходимости соберите и утвердите обновлённый аниматик, затем нажмите **«Подготовить видеопланы из аниматика»**.
7. Откройте новую серию вариантов для видеоплана, проверьте задание и сначала создайте один пробный ролик.

Старые картинки, видео и записи отправленных промптов сохраняются. Новая политика не меняет уже созданный файл; обновлённая постановка появляется в последующих генерациях.

## Передача в видеомодель

Видеопромпт содержит обязательное операторское задание из утверждённого плана. При сокращении длинного запроса этот блок должен сохраняться: нельзя незаметно заменить наезд статичной камерой или потерять конечную крупность, время движения и удерживаемый в кадре объект.

Настройка не добавляет неподдерживаемые параметры к API провайдера. Общий способ передачи движения — текстовое задание в промпте. Результат зависит от выбранной видеомодели и требует просмотра.

Один исходный кадр допускает движение камеры. Второе изображение не становится обязательным только из-за наезда: оно нужно, когда режиссёр отдельно задаёт точную конечную композицию. Политика камеры сама по себе не создаёт новые ключевые кадры и не добавляет искусственный наезд в готовый MP4 аниматика.
