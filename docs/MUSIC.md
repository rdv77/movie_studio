# Музыкальное сопровождение

Отдельный этап **Музыка** расположен после «Видеопланы», перед «Титры». Идентификатор этапа — 11; существующие ID и утверждения проектов не мигрируют. Старые фильмы по умолчанию собираются без музыки.

## Действия режиссёра

1. Утвердите сценарий. В «Музыке» выберите подключённую текстовую модель, введите пожелания и нажмите **Предложить 3 направления с ИИ**. Модель читает полный утверждённый подробный сценарий (если его нет — общий) и визуальный стиль.
2. Выберите понравившееся направление. Его описание переносится в блок генерации. Укажите длительность трека и количество вариантов, затем **Создать музыкальные варианты**. Требуется сохранённый ключ ElevenLabs с доступом к Music API. Платная генерация начинается только после нажатия; оставьте студию открытой для обработки очереди.
3. Альтернативы: загрузите MP3/WAV/M4A/OGG или прослушайте библиотечные треки и нажмите **Добавить к вариантам**. Начальный каталог содержит шесть треков Kevin MacLeod. Другие можно скачать из полного каталога и загрузить самостоятельно.
4. Прослушайте варианты, нажмите **Выбрать**. Включите музыкальное сопровождение, настройте громкость без речи и при речи, начало фрагмента, повтор и плавное начало/конец. Нажмите **Сохранить настройки музыки**, затем **Утвердить музыкальное сопровождение**.
5. Пересоберите MP4 на этапе «Финальная сборка». Ранее созданные MP4 не меняются. При изменении настроек или выборе нового трека требуется утверждение музыки, но утверждения кадров и голосов сохраняются. Отключение сопровождения позволяет собрать фильм без музыки.

Удалённый музыкальный вариант можно восстановить внизу этапа. Файл и расходы сохраняются.

## Громкость и хронометраж

Музыка сводится только в финальном фильме. Аниматик служит проверкой изображения и речи. Сначала рендер измеряет голоса и видео и вычисляет монтажные границы. Интервалы снижения музыки строятся по реальным длительностям утверждённых реплик после их trim и offset, включая закадровую речь. Начало снижения предшествует реплике, восстановление плавное. Музыка не ускоряет, не обрезает и не удлиняет видео или речь.

Перед сведением используемый музыкальный фрагмент нормализуется FFmpeg `loudnorm` к −18 LUFS, затем применяются настройки громкости (по умолчанию 35% без речи и 6% при речи). Значение 0% при речи означает полное затихание. Это автоматизация по интервалу записи; паузы внутри одной реплики не вызывают скачков громкости. Если повтор выключен, короткий трек заканчивается раньше фильма и далее звучит только речь. При повторе стык зависит от выбранной композиции; музыкальное продолжение ИИ автоматически не генерируется.

## API, лицензии и расходы

- Генерация: `POST https://api.elevenlabs.io/v1/music`, `model_id: music_v1`, `force_instrumental: true`, длительность 3–600 секунд. Используется существующий ключ `elevenlabs`, сервер не передаёт его в браузер. [Документация](https://elevenlabs.io/docs/api-reference/music/compose).
- Музыкальные идеи — обычные текстовые модели подключённого провайдера. Возвращаются три описания и ID рекомендованных треков из проверенного каталога; выдуманные ID отбрасываются.
- Каталог и файлы: [официальный Incompetech](https://incompetech.com/music/royalty-free/music.html), [метаданные](https://incompetech.com/music/royalty-free/pieces.json), [лицензии](https://incompetech.com/music/royalty-free/licenses/). Треки распространяются по CC BY 4.0 с указанием автора. Текст атрибуции сохраняется в музыкальном варианте и карточке итогового фильма. **При публикации скопируйте его в описание фильма или титры**; текст не добавляется автоматически на изображение. Студия не покупает альтернативную лицензию без атрибуции.
- Никаких произвольных URL импорта: сервер принимает только ID встроенного каталога; свои файлы загружаются обычным защищённым маршрутом проекта.
- Генерации и анализ попадают в обычный журнал. Тариф ElevenLabs зависит от аккаунта; API не возвращает подтверждённую сумму в этом ответе. Поэтому `actual=null` до сверки. Можно указать оценку одного запроса в USD; лимит бюджета проверяется до постановки серии в очередь. Оценка не выдаётся за факт.
- При потере связи повтор платного запроса не запускается автоматически. Проверка уже завершённой задачи не вызывает провайдера повторно.

## Проверки

`node tests/music.mjs` — авторизация, принадлежность файлов проекту, версии, настройки/утверждения, бюджет, инструментальный запрос ElevenLabs, идеи из сценария, защита от повторных запросов и устаревшей очереди.

`node tests/music-render.mjs` — настоящий FFmpeg WASM: итоговый хронометраж, нормализация, измеренное снижение музыки более чем на 10 dB при речи и восстановление уровня, слышимость голоса, повтор, окончание короткого трека без обрезки фильма и фильм без речи.

Платная генерация во внешнем аккаунте не входит в автоматические тесты; запросы провайдера проверяются на подставленных ответах.
