# Параллельная генерация планов

Для изображений раскадровки и обычных видеопланов студия обрабатывает **до трёх генераций одновременно на проект**. Это могут быть варианты одного плана от разных моделей или несколько разных планов. При старте серии очередь отдаёт предпочтение разным моделям, затем разным планам. Остальные попытки запускаются по мере освобождения мест.

## Несколько моделей для одного плана

1. Откройте нужную карточку → «Создать с ИИ».
2. В «Серии вариантов» отметьте несколько моделей и задайте число вариантов от каждой.
3. Проверьте задачу, первый кадр, героев и оценку расходов.
4. Нажмите «Запустить серию».

## Несколько планов

После запуска серии откройте другую карточку и снова нажмите «Создать с ИИ». Ждать завершения первого плана не требуется. Также можно использовать «Создать оставшиеся планы выбранной моделью»: по одному ролику для каждого отмеченного плана, с тем же общим лимитом параллельности.

Повторную серию для плана с текущей генерацией запустить нельзя. Для сравнения моделей в одном плане отметьте их в одной серии. Попытки с неизвестным исходом сначала проверьте в журнале.

## Что происходит во время ожидания

Если кнопка запуска недоступна, под оценкой серии появляется «Почему запуск недоступен» со списком конкретных планов и причин: длительность, отсутствующий первый кадр или слишком длинный промпт. Например: план 6,5 сек при допустимых 6 сек — превышение 0,5 сек. После снятия галочки с такого плана список причин пересчитывается.

В карточках серии также измеряется реальная длительность утверждённой аудиозаписи с учётом обрезки начала. Интерфейс сравнивает речь с планом и генерируемым роликом. Превышение длины речи — предупреждение для будущего монтажа, а не дополнительный запрет на видеогенерацию: можно создать ролик и затем переозвучить план. Если длительность файла неизвестна, это явно показано; значение из сценария не используется вместо измерения. Для общей дорожки длительность речи по отдельным планам не определяется. При выборе нескольких видеомоделей сравнение выполняется с самым коротким ожидаемым роликом.

Каждая модель получает свой запрос с соответствующим кадром и промптом. Асинхронный ответ провайдера проверяется отдельно; ожидание одной задачи не задерживает остальные свободные места. Задача занимает место до завершения, ошибки или сохранения результата. Лимит проверяется на сервере, в том числе при работе из нескольких вкладок. Все попытки резервируют бюджет; повторная отправка той же серии не создаёт новых платных задач.

Держите студию открытой: она отправляет очередь и проверяет результаты. После закрытия новые запросы и проверки продолжатся при следующем открытии; уже отправленные задачи могут продолжать работу у провайдера. Это не автономный серверный обработчик.

Озвучка, сценарии, создание образов героев и синхронизация губ сохраняют прежний последовательный режим. Пока выполняются задачи другого этапа или синхронизация губ, запуск серии видеопланов заблокирован. Одобрение результатов по-прежнему выполняет режиссёр.
