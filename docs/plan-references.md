# Референсы конкретного плана

В раскадровке и видеопланах автоматический подбор использует текущий утверждённый подробный сценарий. Список `cast` задаёт видимых участников; пустой список означает кадр без персонажей. Рассказчик за кадром и упоминания в соседних планах или истории непрерывности не добавляют портреты.

Для старых сценариев без `cast` используются совпадения имён в описании действия и имя говорящего в кадре. Если соответствие не определено, весь список героев не подставляется. Уточните участников в подробном сценарии или загрузите собственный референс в карточке плана.

Иллюстрация локации автоматически добавляется при совпадении названия её утверждённой карточки с текущим планом или локацией сцены. Общие коллажи стиля не добавляются автоматически: утверждённый стиль остаётся в тексте промпта.

В одиночной генерации показаны подходящие референсы и изображения этого плана; можно снять галочки или загрузить свой файл. Для видео первым кадром предлагаются изображения только этого плана. В массовой раскадровке у каждого плана собственные референсы и галочки; лимиты проверяются отдельно на каждый запрос. Массовое видео также фильтрует героев отдельно для каждого плана.

Изменение подбора действует на новые запросы. Сохранённые материалы, утверждения и ранее отправленные задания не изменяются. Генераторы, требующие входное изображение, не запускаются с пустым набором: добавьте подходящий референс или выберите модель генерации по тексту.
