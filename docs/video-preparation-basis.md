# Актуальность подготовленных видеопланов

Повторная сборка аниматика с теми же исходными файлами не отменяет утверждение видеопланов. ID аниматика, время создания, история выбора кадров, музыка и титры не входят в локальную основу видео.

Новые попытки получают `videoPreparationBasis` версии `vp2` **после** сборки промпта для конкретной модели. Основа фиксирует фактический первый кадр, передаваемый конечный кадр, используемые референсы, преобразования кадра, длительность запроса и постановку текущего плана. Из соседей учитываются только состояния стыков. Модель, которая не принимает конечное изображение, не получает его и не зависит от его замены.

Подготовка хранит отдельный снимок исходных кадров и локальной постановки. Проверка уже подготовленного неизменённого плана не требует актуальности музыки или всех остальных кадров целого фильма. Новое нажатие «Подготовить видеопланы из аниматика» по-прежнему проверяет весь выбранный текущий манифест перед изменениями.

Явно переданный альтернативный кадр остаётся закреплённым за запросом. Автоматически взятый кадр следует соответствующему выбору подготовки. Замена фактического файла, области обрезки, длительности или постановки требует проверки соответствующего результата; изменения соседнего входа/выхода затрагивают необходимый монтажный стык.

Для прежних попыток с полным хешем объекта совместимые хеши сохраняются только при доказанном совпадении исходных файлов, длительности и локальной постановки. Это не миграция всего проекта и не автоматическое утверждение нового материала. Реальная замена источника не наследует прежнее разрешение.

Перед отправкой очереди повторно проверяются локальная основа и замороженные файлы запроса. Устаревшая попытка получает статус «Отменено» и нулевую фактическую стоимость без вызова провайдера. Уже отправленные платные попытки не перезапускаются.

Офлайн регрессия:

```sh
node tests/video-preparation-basis.mjs
```

Тест проверяет четыре плана, совместимость уже утверждённых старых видео после повторного аниматика, историю и происхождение, избирательную проверку стыков, кадры/обрезку/длительность, неподдерживаемые конечные кадры, явные альтернативы и отмену до сетевого вызова. Сравниваются идентификаторы сохранённых файлов: новая загрузка одинаковых пикселей под другим ID считается новым источником.
