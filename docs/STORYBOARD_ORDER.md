# Перестановка планов

На этапе «Раскадровка» выберите карточку, затем используйте «Раньше», «Позже» или «Место в фильме». Изменение сохраняется сразу. Названия и номера внутри названий не переименовываются: место в последовательности показывается отдельно.

Вместе с планом перемещаются связанные карточки озвучки и видеопланов. Изображения, варианты, выбор, актуальные утверждения, титры и настройки длительности остаются у своих сцен. Уже устаревшие материалы не утверждаются автоматически. Аниматик и финальный фильм нужно пересобрать в новом порядке. Общие аудиодорожки с ручными временными смещениями не перемещаются; автоматическая привязка действует для озвучки по планам.

Порядок сохраняется при повторном подтягивании карточек из сценария. Сценарный текст не переписывается. Новые запросы генерации учитывают обновлённые предыдущий и следующий планы; ранее созданное движение камеры не меняется — проверьте стыки при просмотре. Во время активной генерации перестановка недоступна.

Настройка `Project.storyboardOrder` хранит идентификаторы карточек раскадровки. API: `moveStoryboardPlan`, `itemId`, `data: {toIndex}` (позиция от нуля), текущая ревизия проекта. Сопоставление между этапами выполняется по источнику сценария и названию сцены, а не по порядковому номеру.
