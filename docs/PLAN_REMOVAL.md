# Удаление плана из фильма

В «Раскадровке» и «Видеопланах» выберите карточку и нажмите «Удалить план из фильма». В «Аниматике» и «Финальной сборке» кнопка удаления находится у каждого плана монтажной последовательности. Действие выполняется сразу, без подтверждения; оно обратимо.

План исключается сразу из раскадровки, озвучки по планам, аниматика, видеопланов, титров и новой финальной сборки. Остальные актуальные утверждения сохраняются. Исходный сценарный текст не переписывается; генерация оставшихся планов учитывает новых соседей. Повторное подтягивание сценария не возвращает исключённую сцену.

В разделе «Удалённые планы» нажмите «Восстановить план». Карточки, выбор вариантов, медиафайлы, титры и настройки длительности сохраняются. Если с момента удаления изменился сценарий или другая основа, восстановленный материал может требовать пересмотра. План, которого больше нет в актуальном сценарии, нужно сначала вернуть в сценарий.

Ранее собранные MP4 не редактируются: пересоберите аниматик и фильм. Общая озвучка одним аудиофайлом не разбивается автоматически: её нужно отредактировать или перейти к озвучке по планам. Пока выполняется генерация, изменение состава планов недоступно.

API: `removePlan` / `restorePlan` в `PATCH /api/projects/:id`, `itemId` карточки, текущая `revision`. Исключённые связанные карточки хранят `excludedAt` и `planArchive.reason = 'excluded'`; медиа и журналы расходов не удаляются. Восстановление не обновляет устаревшие зависимости автоматически.
