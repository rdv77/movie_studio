# Готовность раскадровки и работа после начальных кадров

В начале страницы «Раскадровка» находится постоянно видимая сводка «Готовность раскадровки». Она считает сохранённые изображения, а не число текстовых вариантов и не число успешных ответов провайдера.

- «Начальные изображения» — у скольких активных планов есть хотя бы один файл первого кадра.
- «Полные наборы изображений» — у скольких планов есть файлы всех необходимых моментов: одного, двух или трёх. Наличие файла ещё не означает выбор варианта.
- «Выбраны комплекты» — у скольких планов выбран каждый необходимый момент. Основа, источник, модель и качество проверяются отдельно перед утверждением.
- «Утверждены планы» — актуальное утверждение полного выбранного комплекта.

«Без начального кадра» сразу показывает именно пропущенные начала. Если такие планы есть, этот фильтр открыт по умолчанию. Кнопка «Не хватает изображений» показывает планы, где хотя бы у одного нужного момента нет файла. В строке видны начало/середина/окончание, миниатюры и состояние генерации. «Требуют внимания» также включает ещё не выбранные и не утверждённые комплекты, изменённую основу и текущую генерацию нового варианта. «Все планы» показывает весь действующий монтажный набор. Удалённые и архивные планы исключены.

«Открыть план» выбирает карточку по её ID и прокручивает страницу к редактору ключевых кадров. Это просмотр; изображения, утверждения и платные задания не меняются. Переход из центра быстрого утверждения также прокручивает к этому редактору.

## Если изображение не появилось

«Создать недостающие первые кадры · N» в сводке открывает общую серию начальных изображений. По умолчанию уже готовые начала не отмечены; конечные изображения не заменяют начальные. Выберите одну модель, проверьте состав и смету, затем «Сгенерировать N картинок».

Если пропущенные планы заблокированы неизвестными исходами, в этом же окне показан их список и кнопка «Разрешить повтор для N пропущенных планов». После проверки старых попыток это явное разрешение снимает блокировку только их начальных запросов и отмечает эти планы для серии. Оно не создаёт новые запросы, не обнуляет расходы и не меняет неизвестный исход. Модель, качество, правки задач и референсов в окне сохраняются. Оплата новой серии начинается только по отдельной кнопке генерации. Действующие запросы, готовые начала, архивные карточки и другие роли таким разрешением не затрагиваются.

1. Откройте «Не хватает изображений» и найдите нужный момент плана.
2. «В очереди», «Создаётся» или «Сохраняется» означают действующую попытку: не запускайте повтор только из-за ожидания.
3. Если показана ошибка, откройте план и журнал, исправьте причину и явно запустите новую попытку. Для начальных кадров можно использовать «Создать кадры всех планов»; по умолчанию выбраны только планы без начального изображения и без блокирующей попытки. Конечный файл не считается готовым началом.
4. При неизвестном исходе сначала проверьте сохранённую попытку в журнале. Сводка не повторяет её и не создаёт новые списания.

Текстовое описание и ответ без сохранённого файла никогда не увеличивают счётчик готовых изображений. Новая попытка или старый сбой не скрывают ранее сохранённую картинку этого же момента.

## После генерации начал всех планов

1. Выберите лучшие начальные изображения. Важны утверждённые лица, одежда, предметы, локация, свет и состояние в начале действия.
2. Проверьте режим «Как показать действие в раскадровке и аниматике». У статичного плана может быть один кадр. У движущегося — начало и окончание; тройной набор дополнительно содержит середину. Не переключайте движущийся план в один кадр только ради обхода отсутствующего окончания.
3. Нажмите «Создать окончания планов» в сводке. Откроется существующая «Ключевые кадры · массовая генерация», роль «Конечный». В этом действии нет отправки в модель: сначала проверьте отмеченные планы, причины блокировки и смету, затем нажмите «Создать ключевые кадры · N».
4. Для созданных ИИ начал модель и качество берутся из выбранного первого кадра каждого плана; сам первый файл передаётся источником. Если первое изображение загружено вручную, выберите модель в поле для таких кадров. Изменённую основу первого изображения сначала нужно проверить для текущей версии в его карточке.
5. Для тройных комплектов повторите массовую генерацию с ролью «Промежуточный · для тройного набора». Для одиночных планов окончания не требуются.
6. Просмотрите и выберите новые изображения в соответствующих ролях карточек. Конечные и промежуточные варианты не утверждаются автоматически. Если изменился выбранный первый кадр, прежнее окончание может требовать пересоздания по новому источнику.
7. Откройте «Проверка и быстрое утверждение», нажмите «Выбрать все готовые», затем «Утвердить отмеченные кадры (N)». Это одно утверждение на весь комплект каждого отмеченного плана. Изменённую основу просматривают и отмечают отдельно; отсутствующие файлы и конфликты не обходятся.
8. Когда все активные планы утверждены, переходите к «Голосам», если в фильме есть речь, затем к сборке «Аниматика» по текущему порядку проекта. После просмотра аниматика можно изменить отдельные изображения или состав планов; видео создаётся на этапе «Видеопланы» по подготовленным кадрам.

## Проверки

`node tests/storyboard-progress.mjs` проверяет роли файлов, неполные наборы, различие наличия/выбора/утверждения, состояния очереди и неизвестный исход, изменённую основу, архивы, массовое создание начал и отсутствие запросов/изменения проекта при просмотре и открытии массового редактора. В тестах нет платных генераций.
