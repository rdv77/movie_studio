# Утверждение наборов раскадровки

Один план получает одно утверждение для выбранного первого кадра, первого и конечного либо первого, промежуточного и конечного. Старые проекты с одной картинкой сохраняют прежнее поведение.

Массовое утверждение обрабатывает только готовые актуальные выбранные наборы. Текстовое описание не заменяет изображение. Отсутствующий кадр, неправильный источник конечного кадра, повтор файла, несовместимая модель или качество остаются причинами, требующими исправления. Изменение другого плана не сбрасывает утверждённый набор с неизменной семантической основой.

Если основа выбранных изображений изменилась, режиссёр должен просмотреть набор и явно подтвердить его. В центре проверки это `reviewed: true`, в карточке — отдельное повторное утверждение. Такое подтверждение сохраняет карточки, файлы, исходные запросы и расходы. Оно не обходит структурные ошибки набора.

`approvalBatch` и `reviewRows` возвращают необязательный `keyframes: {startId, middleId, endId}`. Входы `approveBatch`, `approveReview`, `reapproveUnchangedStoryboard` и `reapproveStoryboard` принимают этот снимок выбора. Старый вход с `itemId` и `variantId` поддерживается; HTTP-обработчик также проверяет ревизию проекта.

Удаление выбранного кадра снимает утверждение набора. Идентификатор отсутствующей роли сохраняется, чтобы другая картинка не подставлялась незаметно. Восстановление возвращает содержимое и не возвращает утверждение автоматически. Все исходные файлы, в том числе архивные аниматики, их манифесты, источники конечных кадров и выборки визуального редактора, остаются доступными владельцу для восстановления. Сборщик файлов не считает произвольные UUID внутри текста файлами.

Каждый выбранный файл проверяется обработчиком утверждения на принадлежность владельцу и соответствие типу, включая конечный и промежуточный кадры. Генерация этого плана блокирует утверждение до готовности. Необязательная визуальная рецензия не блокирует решение режиссёра и не утверждает материал сама.

Проверки: `tests/keyframe-approval.mjs` (11 групп), `tests/keyframes.mjs`, `tests/bulk-approval.mjs`, `tests/storyboard-unchanged.mjs`, `tests/project-assets.mjs`, `tests/variant-removal.mjs`, `tests/directing.mjs`, TypeScript `--noEmit`. Все вызовы провайдеров заменены локальными mock-функциями; платных запросов нет.
