# Сквозная проверка фильма без платных запросов

Из корня самостоятельного `movie_studio`, после установки зависимостей, выполните:

```sh
node tests/full-film-workflow.mjs
```

Тест выполняет настоящие обработчики API, правила проекта, компилятор промптов, адаптеры xAI/MiniMax и монтажный код. Он подменяет приватное хранилище, ключи, HTTP провайдеров и загрузку браузерного worker. Неизвестный сетевой адрес вызывает ошибку; реальные запросы и платные генерации не выполняются. Для параллельных агентов хранилище имитирует проверку ревизий и повтор CAS, а не просто перезаписывает состояние.

Проверяется последовательность:

1. Исходный сценарий, творческое задание со шкалами, визуальный стиль, сохранённые герой и локация.
2. Разделение на сцену, режиссёрская проработка двух планов, оператор, художник, реплики, актёрская работа, рецензент сцены и общий редактор. Промпты реально проходят текстовый адаптер; результаты сохраняются по штатным правилам.
3. Явное утверждение планов и публикация подробного сценария, подготовка карточек раскадровки.
4. Четыре изображения: начало/конец каждого из двух планов. Проверяются `medium/2k`, обязательная идентичность/одежда/локация, исходный первый файл при создании конечного, серверная смета и отсутствие повторных POST.
5. Массовое утверждение пар и реальная сборка десятисекундного аниматика через FFmpeg WASM. Проверяются четыре цветовых маркера кадров, их порядок и сохранённый манифест.
6. Подготовка видео именно по исходным ID из манифеста. Настоящий Grok-адаптер передаёт приватные файлы отдельно в `image` и `last_frame`; запрашиваемая длительность и резерв проверяются до отправки. Проверка готовности результата не создаёт новую генерацию.
7. Профиль выбранного голоса, удаление служебного имени из реплики, неизменная постановка TTS. Первая тестовая запись содержит 6.25 секунды звука при видеоплане 5 секунд; MP3 дополнительно содержит задержку кодека. Реальная сборка измеряет готовый MP3 и отказывает, сохраняя состояние и полный звук.
8. Явно запрошенная новая озвучка, явный выбор и массовое утверждение замены. Она не меняет выбранный голос автоматически и не отменяет готовое видео в режиме «сначала видео».
9. Настоящий финальный MP4: ffprobe подтверждает 10 секунд, видео и аудиодорожку; пиксели подтверждают порядок кадров; измерение громкости подтверждает звук только внутри нужного плана и тишину до/после него. Фильм сохраняется и утверждается штатным API. Чужой файл и неавторизованное изменение отклоняются без частичной записи.

Результаты сохраняются локально:

- `work/tests/full-film-animatic.mp4` — парный аниматик;
- `work/tests/full-film-final.mp4` — финальная сборка с заменённой озвучкой.

Для скорости видео теста имеет разрешение 160×90 с тем же соотношением 16:9. Картинки — различимые цветовые маркеры; запись — синтетический тон. Это проверка передачи оригинальных файлов, порядка монтажа, попадания аудио в нужный план и защиты от повторной оплаты. Она не подтверждает художественное качество живой генерации, разборчивость реального голоса, движение камеры или синхронизацию губ. Эти свойства требуют отдельной проверки полученного медиа и просмотра режиссёром. Тест не подменяет весь фильм заранее готовым JSON: оба MP4 собирает код приложения из сохранённых исходных файлов.

Для всех локальных проверок: `node tests/all.mjs`. Сквозной тест входит в этот прогон автоматически; вызовы провайдеров подменены. Реальные серверные/container smoke tests запускаются отдельно согласно существующей документации развёртывания.
