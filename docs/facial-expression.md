# Настройка мимики

В «Общем сценарии» → «Творческое задание» появился выбор «Мимика героев · для фильма». После выбора нажмите «Сохранить творческое задание».

| Режим | Задание для постановки |
| --- | --- |
| По жанру и характеру | Учитывать жанр, характер и ситуацию; по умолчанию естественно, без преувеличения. |
| Сдержанно | Тонкие изменения взгляда, бровей и выражения лица. |
| Естественно | Живые, правдоподобные реакции без переигрывания. |
| Мультяшно | Более выразительные анимационные реакции с сохранением узнаваемости. |
| Гипертрофированно | Сильные реакции в эмоциональных пиках, спокойнее между ними; без постоянных гримас. |

В «Подробном сценарии» откройте нужный план → «Правки четырёх частей» → «Мимика этого плана». «Как в фильме» наследует общую настройку; любой из пяти режимов переопределяет её. Явный выбор «По жанру и характеру» тоже является переопределением, даже если для фильма выбрано «Мультяшно».

Сохраните и утвердите отредактированный план, затем примените подробный сценарий штатной кнопкой подготовки промптов. Новые генерации получат настройку применённого плана. В «Актёрских задачах» можно дополнительно описать наблюдаемую игру, начальную и конечную эмоции. Уже созданные файлы сами не изменяются.

Общая настройка мимики предназначена для будущих генераций. Её изменение само по себе не снимает утверждения существующих материалов. Изменение постановки отдельного плана остаётся обычной правкой этого плана. Остальные изменения творческого задания сохраняют прежние правила пересмотра.

## Как настройка применяется

- Агент получает разрешённую выразительность каждого прорабатываемого плана. Он описывает реакции с учётом героя и ситуации, но не переписывает пользовательский выбор режима.
- При подготовке изображения или видео режим добавляется отдельным компактным обязательным блоком. Для начальной и конечной картинки сохраняются соответствующие эмоции, для видео — наблюдаемая игра и переход между ними.
- При LLM-сокращении для блока режима заранее резервируется место. Программа сохраняет его исходный текст независимо от того, что вернул оптимизатор. Остальные обязательные сведения допускают компактное перефразирование; итоговый лимит API проверяется после сборки.
- Узнаваемые черты лица сохраняются. Для неговорящего героя запрещена речевая артикуляция, но разрешены мимика глаз и бровей и улыбка с закрытым ртом. Настройка не включает синхронизацию губ автоматически.

Это управление заданием модели, а не гарантия конкретного результата: качество мимики зависит от видеомодели, крупности, видимости лица и исходных кадров. Платная генерация для проверки настройки не запускается автоматически.

Старые проекты не мигрируются: отсутствие поля означает наследование и естественный режим по жанру и характеру. Схемы, история и экспорт сохраняют явно выбранные значения.

## Проверка

`npm run test:facial-expression` проверяет режимы, наследование, защиту при сокращении, сохранение утверждений через API и интерфейс. API провайдеров подменяются; тесты не запускают платную генерацию.
