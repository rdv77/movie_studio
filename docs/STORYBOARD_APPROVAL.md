# Утверждение раскадровки после правок

После утверждения новой версии подробного сценария откройте «Раскадровку». При необходимости сначала нажмите «Подготовить планы», чтобы обновить состав карточек.

В блоке «Утверждение выбранных вариантов» появится кнопка **«Утвердить неизменившиеся планы · N»**. Раскройте «Какие планы будут утверждены», чтобы увидеть список, затем нажмите кнопку. Изображения сохраняются; повторная генерация и создание копий не выполняются.

В эту группу попадают только выбранные варианты с прежним утверждением, для которых сохранился соответствующий план и не изменились его описание, камера, речь, говорящий персонаж, длительность и монтаж. Проверяется версия сценария на момент последнего утверждения, а не только исходной генерации. Изменения общей основы — настроек фильма, общего сценария, героев, стиля, образов и общих указаний подробного сценария — требуют отдельной проверки.

Новые выбранные варианты, изменённые планы и карточки, для которых нельзя надёжно восстановить прежнюю основу, перечислены в «Какие карточки требуют внимания». Откройте такой план, проверьте кадр и используйте «Утвердить раскадровку для текущей версии», если результат всё ещё подходит. Либо внесите правки/создайте новый кадр и утвердите его обычной кнопкой.

Правка одной карточки непосредственно в раскадровке не сбрасывает утверждения остальных карточек того же этапа. Переутверждение раскадровки не утверждает автоматически голоса, аниматик и видео.

Если новая версия сценария ещё не утверждена или выполняется генерация, сначала завершите эти действия. Проверка повторяется на сервере; изменение проекта в другой вкладке потребует обновить страницу перед утверждением.

## Следующий этап: голоса

На этапе «Голоса» кнопка **«Утвердить все неутверждённые»** также повторно утверждает прежние выбранные записи по планам, если изменились только изображения или другие визуальные детали. Студия сравнивает текст, говорящего, вид речи и длительность каждого плана на момент последнего утверждения и сейчас. Аудиофайлы, выбранные голоса и монтажные настройки записи сохраняются.

Изменённые реплики, новый выбор вместо прежнего голоса, общая дорожка и записи без проверяемой истории остаются для отдельного прослушивания. Причина указана в «Какие карточки требуют внимания». Предыдущие этапы должны быть утверждены, а текущие задачи генерации завершены.
